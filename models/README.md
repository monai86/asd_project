# Models

This folder contains compatibility exports for CHA transcript classifier
deliverables.

The runtime model artifact for the therapist app is:

- `artifacts/screening_model.joblib`

The compatibility export path is:

- `models/transcript_classifier.pkl`

Both files should contain the same model bundle when generated by
`packages/ml/train_model.py`.

The model output is Reference Cohort Similarity. It compares transcript feature
patterns with reference cohort labels such as ASD, TD, and DD. It does not
diagnose ASD and must be reviewed by a qualified clinician.

Acoustic profile values are context-only indicators in this iteration and are
not classifier inputs.
