# Add parallel Next.js Therapist App v2

The attached Therapist App v2 plan requires a new `apps/therapist-app-v2/` Next.js surface and `apps/api/` FastAPI boundary, which supersedes the earlier v2 direction of evolving only the existing Vite/Capacitor clinician app. We will keep the existing app intact as the legacy prototype while adding the parallel v2 MVP so the manual-first, case-centered workflow can be implemented cleanly without deleting existing Supabase, PWA, and native-shell work.
